i.

書房裡的幾個角落

不只是一張書單。每個角落，都是為了讓你更想回來翻一翻。

按月份排好的書架

書依照讀完的月份由左到右排在書架上，每個月前面立著一張月份卡。有封面的書正面朝外，沒有封面的書會自動做成一本布面書背。

  • 頂端有「每月讀了幾本」的長條圖，點一下就跳到那個月
  • 可以切換成封面牆，一次看整年的封面
  • 關燈之後是夜讀模式，檯燈的光會跟著游標走

翻開一本書，留下當時的自己

點書架上的任何一本，它會從架上抽出來、攤開成跨頁：左邊是封面，右邊是讀完的月份、作者、標籤，和你寫在橫線紙上的一句感想。

  • 一鍵「放進珍藏」，所有年份喜歡的書會集合在同一面展示櫃
  • 可以替書加標籤，例如小說、理財、散文
  • 左右鍵或手機滑動，就能一本接一本翻下去

年度回顧，和隨手抽一本

年底按下「年度回顧」，像翻相簿一樣一頁一頁看：讀了幾本、哪個月讀得最起勁、這一年的第一本和最後一本、你放進珍藏的那幾本。

  • 「隨手抽一本」會從所有讀過的書裡洗牌抽出一本，提醒你那是幾年前讀的
  • 搜尋可以跨所有年份，找書名、作者、標籤或筆記

ii.

三個步驟，開始你的書房

打開網頁就能用，不用下載、不用註冊帳號。

1

放上第一本書

按「放一本書」，填書名、點選讀完的月份就好。作者、標籤、感想都可以之後再補。

2

替它找一張封面

按「到博客來找封面」，用螢幕剪取框選封面（Windows Win＋Shift＋S），回來按 Ctrl＋V 貼上。多框到的白邊會自動修掉。

3

已經有書單？直接匯入

Excel 書單只要有「書名、年份、月份」三欄就能匯入，貼在格子裡的封面圖也會一起帶進來。書房裡有範本可以下載。

iii.

你的書，只在你手上

書房沒有伺服器，也不收集任何資料。

存在你的瀏覽器裡

所有紀錄都存在你自己裝置的瀏覽器中。別人打開同一個網址，看到的是他自己的空書房，看不到你的書。

隨時匯出備份

可以匯出 JSON 完整備份（含封面圖），或 Excel 試算表。換裝置時再匯入，就能把整座書房搬過去。

手機、電腦同步

想在多台裝置之間自動同步，可以連到你自己 GitHub 上的私人儲存庫。資料只放在你的帳號裡，書房裡有一步一步的設定說明。

iv.

常見問題

需要付費或註冊嗎？

不用。打開網頁就能直接使用，也沒有廣告。

清除瀏覽器資料後，書會不見嗎？

會。因為紀錄存在瀏覽器裡，清除網站資料就會一起刪掉。建議定期匯出備份，或設定 GitHub 同步；書房選單裡會提醒你上次備份是什麼時候。

換新手機要怎麼把書搬過去？

在舊裝置匯出 JSON 備份，到新裝置的書房選「匯入資料」選那個檔案。若有設定 GitHub 同步，新裝置連上同一個儲存庫就會自動帶過來。

可以分享我的書房給別人看嗎？

目前不行，書房是只給自己看的。可以把網址分享給朋友，讓他們建立自己的書房。
